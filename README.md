# Оно тебе надо

Лендинг аукциона «Оно тебе надо» — вещей, в которые никто не верил, но которые стали культовыми.

Репозиторий проекта: https://github.com/Errwith/ono-tebe-nado-ad

## О проекте

Одностраничный сайт свёрстан по макету: шапка с навигацией и контактами, обложка с заголовком и кнопкой ставки, блок лотов из трёх карточек, секция «Об аукционе» и подвал с контактами, меню и ссылками на соцсети.

## Стек

- HTML5 (семантическая разметка)
- CSS3 (Grid, Flexbox)
- Шрифт Raleway в форматах `woff2` и `woff`

Откройте [`index.html`](index.html) в браузере (Firefox, Google Chrome или Yandex Browser). Дополнительная сборка не требуется.
